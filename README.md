# 🏠 Go Home Reminder

یک اپلیکیشن ساده و کاربردی برای یادآوری زمان پایان کار و خروج از محل کار، مخصوص افرادی که شغل کارمندمحور دارند.

## ✨ معرفی

این برنامه ساعت ورود شما را دریافت می‌کند و زمان خروج را محاسبه می‌کند. سپس زمان خروج را در **Windows Task Scheduler** ثبت می‌کند تا دقیقاً در ساعت خروج، یک نوت‌پد با پیام زیر نمایش داده شود:

Work is over!
Time to go home!
It's time to relax! 😊️
هدف این برنامه کمک به مدیریت بهتر زمان کاری و یادآوری پایان روز کاری به شکلی ساده و مؤثر است.

## 🚀 نحوه استفاده

1. فایل اجرایی (`.exe`) برنامه را دانلود کنید یا خودتان از سورس کامپایل کنید.  
2. پیشنهاد می‌شود فایل اجرایی را داخل پوشه‌ی **Startup** ویندوز قرار دهید تا هر روز صبح به صورت خودکار اجرا شود.  
3. برنامه به صورت خودکار ساعت ورود را دریافت کرده و زمان خروج را تنظیم می‌کند.  
4. در زمان خروج، نوت‌پد با پیام یادآوری باز می‌شود. 🕒📢

## 💻 پیش‌نیازها

- ویندوز (Windows 10 یا بالاتر توصیه می‌شود)  
- اجازه دسترسی به Task Scheduler برای ثبت زمان خروج
